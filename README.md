# Radioactive-decay-simulation
Python-based project simulating radioactive decay using exponential decay law and Matplotlib.
This Python script models the exponential decay of a radioactive iaotope using Numpy and Visualizes the decay curve using Matplotlib
### Features:
-uses exponential decay law: N(t)=N0*exp(-lambda*t)
-Adjustable half-life, starting nuclei count and time window
Matplotlib-based visualization

## Tools used:
-Python
-Numpy
-Matplotlib

Feel free to use/extend this code.
